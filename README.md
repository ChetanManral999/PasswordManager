# Password Manager

A lightweight Password Manager built entirely in Python that helps users securely manage their login credentials. The application allows users to save website names and passwords in a text file, generate strong random passwords, and view previously saved credentials through a simple and user-friendly interface.

## Features

* Save website names and passwords to a text file
* Generate strong random passwords automatically
* View all saved website credentials
* Simple and lightweight Python application
* Easy-to-use interface

## Tech Stack

 Python

## How It Works

1. Enter the website name.
2. Generate a secure random password or enter your own.
3. Save the website and password to a text file.
4. View all previously saved credentials whenever needed.
